Cấu hình Google Drive API (OAuth 2.0)

Hướng dẫn lấy Google OAuth Client ID (miễn phí):

  1. Truy cập Google Cloud Console → Tạo Project & bật Google Drive API.
  2. Vào Credentials → Create Credentials → OAuth client ID (Loại: Web application).
  3. Thêm domain hiện tại của trang web vào mục Authorized JavaScript origins, sau đó dán Client ID vào ô bên dưới.
Quyền yêu cầu: drive.file (chỉ quản lý file do app tạo)
